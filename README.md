# Velocity Motors React Project

Velocity Motors is a luxury and performance car rental website made using ReactJS and CSS.

The website includes:
- Home page
- Models page
- About page
- Contact page
- Booking form
- Rental price calculation
- Order status dashboard
- Responsive design

Technologies used:
- ReactJS
- React Router
- CSS3
- Bootstrap
- Vite

How to run:

```bash
npm install
npm run dev
```
